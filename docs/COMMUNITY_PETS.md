# Community pets / 社区宠物

[中文](#中文) | [English](#english)

<a id="中文"></a>
## 中文

这里是 `dsh-pet` 社区宠物的展示与贡献入口。项目随包提供 DeepSeek Whale 作为格式示例；任何符合 [宠物包入门](PET_PACKS.md) 的原创或已获授权角色，都可以成为社区宠物。

### 现有示例

| 宠物 | 类型 | 说明 |
|---|---|---|
| DeepSeek Whale | 内置示例 | 展示 192×208、8 列、9 行 WebP atlas 与最小清单 |

### 提交方式

创建 “Share a pet pack” Issue，并提供：宠物名、许可证或再分发许可、预览图或 GIF、支持的 DSH 版本、atlas 规格，以及指向可公开获取源码或资源的链接。维护者只会收录可验证来源和明确许可的资源。

<a id="english"></a>
## English

This page is the display and contribution entry point for `dsh-pet` community pets. DeepSeek Whale ships as a format example; any original or properly licensed character that follows [Create a pet pack](PET_PACKS.md) can become a community pet.

### Included example

| Pet | Kind | Notes |
|---|---|---|
| DeepSeek Whale | Bundled example | Demonstrates a 192×208, 8-column, 9-row WebP atlas and the smallest manifest |

### How to submit

Create a “Share a pet pack” Issue with the pet name, license or redistribution permission, preview image or GIF, supported DSH version, atlas specification, and a public source or asset link. Maintainers list only resources with verifiable provenance and clear permission.
