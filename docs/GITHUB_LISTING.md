## Release title and opening

```text
dsh-pet v0.1.1-rc.3 — Customizable Desktop Pets for DeepSeek Harness
```

~~~markdown
Bring your own sprite-based character to DeepSeek Harness.

- Import validated local pet packs; DeepSeek Whale is the included example.
- Reflect agent activity in the DSH Web UI.
- Use an optional transparent Electron desktop companion where the host supports it.
- Keep pet resources local without adding model input or token cost.

Install:

```sh
dsh plugin --profile web add @luv1211/dsh-pet-desktop@0.1.1-rc.3
```
~~~
