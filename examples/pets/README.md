# Example pet packs / 示例宠物包

[中文](#中文) | [English](#english)

<a id="中文"></a>
## 中文

本目录包含可复制到本地 DSH 宠物根目录的完整示例包。它们用于演示 `dsh-pet` 是可导入自定义角色的系统，而不是固定为某个内置角色的插件。

| 包 | atlas | 许可证 | 说明 |
|---|---:|---|---|
| [`nailong/`](nailong/) | 8×9 v1 | MIT | 仓库所有者授权公开再分发的黄色角色示例包。 |

每个包都包含自己的 `pet.json`、`spritesheet.webp` 与许可证说明。把整个包目录复制到配置的 pet root，再在 **设置 → Pet** 中刷新目录。

<a id="english"></a>
## English

This directory contains complete examples that can be copied into a local DSH pet root. They demonstrate that `dsh-pet` imports custom characters instead of being tied to one bundled character.

| Pack | Atlas | License | Notes |
|---|---:|---|---|
| [`nailong/`](nailong/) | 8×9 v1 | MIT | Yellow-character example pack authorized for public redistribution by this repository's owner. |

Each pack includes its own `pet.json`, `spritesheet.webp`, and license notice. Copy the whole package directory into the configured pet root, then refresh the catalog in **Settings → Pet**.
